# registry/ — سجل النماذج والمؤشر الأفضل

هذا المجلد يحمل **البيانات الوصفية لكل إصدارات النموذج**: الخريطة التي تربط كل إصدار بأصوله وأدلته — الأوزان نفسها في التخزين الثلاثي (ADR-0009).

## البنية المستهدفة (من `PLAN.md` §4 و§8)

```
registry/
  models.json      # لكل إصدار: الأساس + إصدار البيانات + نتائج البطارية + روابط الأصول (HF/Releases) + SHA256
  CURRENT.md       # المؤشر إلى «أفضل نموذج معتمد حاليًا» ولماذا
```

## القواعد

1. **لا إدخال بلا دليل:** كل إصدار في السجل لا يُسجل إلا بعد عبور بوابة G-Q بنتائج موقعة في `evaluation/results/`.
2. **التاريخ كامل:** الإصدارات المرفوضة تُوثَّق أيضًا (مع سبب الرفض) — سجل التعلم في `memory/` يحمل القصة الكاملة.
3. **إعادة البناء:** من هذا السجل وحده يمكن استرجاع أي إصدار: تنزيل الأصول بالروابط والتحقق بـSHA256 + تنزيل الأساس العام + تشغيل البطارية ومطابقة النتائج (عقد ADR-0009).
