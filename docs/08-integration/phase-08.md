# المرحلة 8 — التكامل مع Alkemos وEVO

> إصدار: v1.0 (خطة) · تاريخ: 2026-11-22 · **الحالة: ⬜ مخططة — تفتح عند جاهزية المحرك (بعد G2+G3)** · التبعيات: 4 ✅ + 7 (G3)

## 1. الهدف

تشغيل محرك AlkemosAI بالتوازي مع نظام Alkemos الحالي، بتوجيه تدريجي للمهام المناسبة، دون أي تعطيل أو تأثير على الإنتاج أو الحصص أو الاشتراكات، وبخطة رجوع فورية.

## 2. مبادئ التكامل (من خط الأساس — إلزامية)

1. **صفر تعديل إنتاجي دون أمر مالك مستقل** — التكامل كله يبدأ خارج الإنتاج ثم يدخل بقرارات موثقة.
2. **الحفاظ على الأنظمة الحالية:** الحصص الشهرية (خصم عند النجاح فقط)، التبريد، العدادات، الاشتراكات — كلها كما هي؛ المحرك الجديد يُستهلك **خلف** نفس هذه البوابات.
3. **التراجع بمتغير واحد** — النمط الموروث (`legacy`): توجيه المهمة يعود للسلسلة القديمة بلا نشر.
4. لا هدر لأصل مجاني: مزودو APIs الحاليون يبقون **المخزن الاحتياطي** للنقطة الذاتية والعكس.

## 3. مسار التكامل المتدرج (تصميم)

**المرحلة 8-أ (خارج الإنتاج):** تشغيل محرك AlkemosAI كخدمة مستقلة + بطارية مقارنة يومية آلية على نفس المدخلات (حالات مرآتية منزوعة الهوية) — تقرير تعادل أسبوعي.

**المرحلة 8-ب (وضع الظل):** داخل بيئة Alkemos، استدعاء مرآتي بعد الاستدعاء الأصلي (بلا تقديم للمستخدم، بلا تكلفة إضافية على المسار الحرج) — قياس تعادل حي على حركة حقيقية بعد تصاريح المالك.**حصريًا بمهام الطابور الدفعي أولًا** (خطط/مقالات — لا محادثة EVO الحساسة للزمن).

**المرحلة 8-ج (توجيه أولي):** بقرار مالك وبعد ثلاثة أسابيع تعادل ≥95%: توجيه **مهمة واحدة** (المرشح: `plan:nutrition` — الأعلى انضباطًا وأسهل تقييمًا) بنسبة 5% من الطلبات → مراقبة → توسيع تدريجي 25% ← 100%.

**المرحلة 8-د (توسيع حذر):** إضافة `plan:workout` ثم مهام المدونة الدفعية. **EVO (السلسلة السريعة) آخر ما يُوجَّه** وأول ما يُتراجع عند أي شك (زمن الاستجابة حرج).

## 4. خطة الرجوع (Rollback) — تصريف كامل

- مستوى 1: متغير بيئة يعيد المهمة للسلسلة القديمة (ثوانٍ، بلا نشر).
- مستوى 2: إيقاف النقطة الذاتية كليًا مع تحويل تلقائي للمخزن الخارجي (نمط السلاسل الموروث).
- مستوى 3 (كارثي): عزل خدمة AlkemosAI كاملة عن الإنتاج — الإنتاج يعود لوضع ما قبل التكامل حرفيًا.
- **شرط الرجوع (أي منها):** انحدار بطارية حي >1% · أي فشل سلامة · زمن استجابة P95 خارج الاتفاق.

## 5. المهام التفصيلية

1. ⬜ وثيقة تكييف الاستهلاك: أصغر تغيير ممكن في Alkemos ليتكلم مع الواجهة الموحدة (الهدف: base_url + مفتاح + رأس مهمة — ADR-0005).
2. ⬜ موافقة المالك الموثقة لكل مرحلة (8-ب/ج/د قرارات مستقلة).
3. ⬜ لوحة مراقبة مزدوجة: تكلفة/جودة/توفر للمسارين معًا (بنمط عدادات خط الأساس).
4. ⬜ تدريب رجوع شهري (تمرين فعلي للمستوى 1) — إثبات جاهزية التراجع.

## 6. معايير النجاح

- وضع الظل يعمل أسبوعًا كاملًا بلا أي أثر إنتاجي (سجلات نظيفة).
- أول مهمة ذاتية بنسبة 100% لمدة شهر بتعادل موثق وتراجع مجرب.

## 7. المخاطر
