# المرحلة 6 — التعلم والتطوير (Fine-tuning وما بعده)

> إصدار: v1.0 (خطة) · تاريخ: 2026-11-21 · **الحالة: ⬜ مخططة — تبدأ بعد اكتمال 5 (وقبول 2 عمليًا)** · التبعيات: 2 + 5

## 1. الهدف

تحسين مستمر مضبوط ومراقب: LoRA/QLoRA على مرشحنا، بيانات متخصصة عالية الجودة، تعلم من تغذية راجعة معتمدة، دون إفساد القدرات السابقة — ودراسة الجدوى المستقبلية لنموذج أساسي خاص (L4).

## 2. لماذا الترتيب LoRA/QLoRA أولًا [موثق بالأسعار، يونيو–نوفمبر 2026]

- جولة LoRA لنموذج 7–8B: **$3–10** · 70B QLoRA: **$15–30** — أي أن التجريب ضمن سيناريو «منخفض» الميزاني.
- التدريب الكامل والنموذج الأساسي الخاص: **GPU-أشهر + بيانات بالمليارات** — خارج أي ميزانية حالية؛ يبقى دراسة جدوى تتغذى من تراكم مرحلتي 5 و6 (قرار L4 مستقبلي بمعطيات حقيقية).

## 3. البيانات (من مرحلة 5)

1. أسئلة/إجابات متخصصة ثنائية اللغة مؤلفة ومراجعة بشريًا (عربية أصيلة لا مترجمة).
2. بيانات تركيبية (Synthetic) **بضوابط**: توليد بحالة تحكم معتمدة + بوابات جودة + رفض أي مصدر يمنع ترخيصه التدريب على مخرجاته (فحص ترخيص لكل مصدر — R-08).
3. تعلم من تغذية راجعة **معتمدة**: تقييمات 👍/👎 ومخرجات اجتازت بوابات الإصلاح (ذيل نجاح) بعد تجريد الهوية وموافقة المالك — نمط الإشارات الموجود أصلًا في EVO.

## 4. دورة التدريب الآمنة

```bash
# (أوامر مرجعية عند فتح المرحلة — GPU مؤجرة)
# 1) إعداد بيئة (Unsloth على RunPod)
pip install unsloth datasets
# 2) ضبط دقيق QLoRA على بياناتنا
python train/sft_qlora.py --base <المرشح> --data data/sft/v1-ar-en.jsonl \
  --lora-r 16 --epochs 2 --out runs/v1
# 3) دمج + تكميم + تشغيل ذاتي
# 4) تشغيل بطارية المرحلة 7 كاملة قبل أي اعتماد — وقاعدة:
#    "لا دمج بلا اجتياز البطارية دون انحدار" (ضد R-03)
```

**قوانين الدورة:** قبل/بعد بنفس البطارية · حفظ نقاط كل نسخة بمعرف · سجل تدريب موثق (بيانات/معاملات/نتائج) · إلغاء تلقائي عند أي انحدار >1% في أي مجموعة فرعية حرجة (العربية، الأرقام، السلامة).

## 5. المهام التفصيلية

1. ⬜ أول 500–1,000 زوج تدريب عربي/إنجليزي مراجعة (بناء مع مرحلة 5).
2. ⬜ أول LoRA تجريبي + تقييم كامل موثق.
3. ⬜ بروتوكول منع النسيان الكارثي: مزيج بيانات مراجعة (rehearsal) + تقييمات مجموعات متعددة.
4. ⬜ دراسة التقطير من مرشح كبير إلى صغير — **مشروطة بترخيص المصدر يسمح صراحة**.
5. ⬜ دراسة ملكية حقيقية: حقوق بيانات التدريب/الأوزان الناتجة/المخرجات لكل ترخيص مستخدم — توثق في ADR مستقل قبل أول دمج إنتاجي.
6. ⬜ (لاحقًا) ورقة جدوى L4: حجم بيانات مطلوب، تكلفة GPU-شهر، عائد متوقع على تخصصاتنا.

## 6. معايير النجاح

- أول LoRA يجتاز البطارية كاملة (≥ مستوى الأساس في كل شيء + تحسن في العربية/الأسلوب ≥3%).
- سجل تدريب كامل قابل لإعادة الإنتاج (بيانات+معاملات+كود) — عمود الملكية 6.

## 7. المخاطر

R-03 (انحدار صامت) · R-08 (تراخيص بيانات تركيبية/تقطير) · إفراط تدريب على نمط ضيق (تخفيف: بيانات متنوعة + مجموعات مراقبة).
