# المرحلة 5 — البيانات والمعرفة والذاكرة

> إصدار: v1.2 · تاريخ الإنشاء: 2026-11-21 · **الحالة: 🔄 نشطة جزئيًا (بدأت بأمر المالك D-16 — 2026-11-24 UTC، قبل التسلسل الأصلي «بعد اكتمال 4» — طبقة الذاكرة والمعرفة فقط بلا أي تداخل مع M2/القياس — **دفعة 16-تتمة:** تحصين ثغرات مراجعة المحرك الخمس بتنفيذ واختبارات 225/225 منها 40 سلبية — تقرير الإغلاق `batch16-hardening-closure-report-2026-11-24.md`)** · التبعيات الأصلية: المرحلة 4 (لم تعد مانعة لأبواب الذاكرة النقية بأمر المالك)

## 1. الهدف

بناء قاعدة معرفة علمية متخصصة + ذاكرة طويلة الأمد قابلة للنقل + سياسات بيانات للتدريب، مع فصل صارم بين ما يُدرَّب عليه وما يبقى استرجاعًا.

## 2. قاعدة المعرفة العلمية (KB)

**المجالات:** تدريب الرياضة (فسيولوجيا/تخطيط أحمال/دورات)، تغذية (احتياجات/أغذية/حسابات)، صحة عامة تثقيفية.

**مصادر معتمدة (تُجمع بتوثيق رابط + تاريخ + ترخيص استخدام):**
- إرشادات منظمة: WHO (تغذية/نشاط)، ACSM (تدريب)، AND (مغذيات)، CDC/NHS (تثقيف صحي).
- مراجعات منهجية وmeta-analyses من PubMed/Cochrane.
- **أصل جاهز:** مكتبة Alkemos المنسقة (868 تمرينًا + 8,162 صنف طعام معرّبًا + 7 برامج + بوابات التدقيق) — تُستأنف بترتيب مالك لأنها أصل منتج.

**بنية KB:** وثائق Markdown منظمة + بيانات منظمة (JSON) + طبقة استرجاع هجينة (BM25 + متجهات بتضمين عربي/إنجليزي مملوك) + **إلزام استشهاد** في كل معرفة يقدمها المحرك (ضد الهلوسة R-09).

**سياسة التحديث والتصحيح:** كل وثيقة معرفة تحمل تاريخ مراجعة ومصدرًا؛ التصحيح يعمل بطلب «تصحيح موثق» يمر بمراجعة قبل الدمج؛ سجل تغييرات المعرفة ضمن المستودع.

## 3. الذاكرة طويلة الأمد

**ثلاث خزانات منفصلة (تصميم):**

| الخزانة | المحتوى | التخزين | الخصوصية |
|---|---|---|---|
| ذاكرة مستخدم | تفضيلات/قيود/تقدم (نمط `evo_memory` الموروث: استخراج دوري + قائمة حجب PII + حقن محدود) | Postgres نملكه + تصدير JSONL | بيانات صحية — لا تغادر بيئتنا، تجريد قبل أي تدريب |
| ذاكرة تنظيمية | قرارات/دروس/نتائج تقييم/خبرات تشغيل | ملفات في هذا المستودع + قاعدة بيانات | داخلية |
| معرفة عامة | قاعدة المعرفة العلمية | مخزن KB (§2) | مصادر مرخصة |

**قابلية النقل (عمود 5):** تصدير كامل بوصفة واحدة (`export --all`) بصيغ مفتوحة، واختبار استيراد في بيئة نظيفة ضمن ساعة.

## 4. ما يُدرَّب وما يبقى RAG (السياسة)

- **RAG:** كل معرفة علمية قابلة للتغير، كل ما يحتاج استشهادًا، كل بيانات منتج حية.
- **تدريب:** أسلوب اللغة والأسلوب التحريري ونمط الإجابة والاصطلاح العربي المتخصص — لا الحقائق القابلة للتغير.
- **قاعدة سلامة:** لا بيانات مستخدمين في أي تدريب دون (أ) تجريد هوية كامل (ب) موافقة مالك مستقلة موثقة (R-07).
