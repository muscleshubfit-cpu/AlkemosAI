# FOUNDATION_INSTRUCTIONS — التعليمات التأسيسية الموحدة لكل المراحل

> إصدار: v1.0 · تاريخ: 2026-11-22 · **هذا الملف مرجع موحد تشير إليه جميع وثائق المراحل — لا يُكرر محتواه فيها.**

## 1. منهجية البحث والمصداقية (ملزمة في كل مرحلة)

1. **البحث فعلي على الإنترنت** — لا اعتماد على الذاكرة النموذجية في أي رقم أو سعر أو إصدار أو ترخيص.
2. المصادر المعتمدة: الوثائق الرسمية، مستودعات النماذج (ملفات LICENSE الفعلية لا وصفها)، صفحات الأسعار الرسمية، الاختبارات المستقلة. **لا دعاية تسويقية.**
3. كل مصدر يوثق في `references/sources-log.md` بـ: الرابط + **تاريخ الاطلاع** + ما يؤكده.
4. **الفصل الصارم بين:** [مُقيس] (قياس من كود/سوق/API) / [موثق] (مستندات المشروع) / [تقدير] (حساب استنتاجي) / [غير متحقق].
5. ممنوع اختراع أسعار أو مواصفات أو نتائج اختبارات — ما لم يُعثر عليه يُكتب صراحة «غير متحقق حتى 2026-11-22».
6. «مفتوح الأوزان» ≠ «مملوك قانونيًا بالكامل»: يفحص كل ترخيص من مصدره للاستخدام التجاري + التعديل + التدريب على المخرجات + التقطير.
7. المعلومات غير المتحقق منها تُذكر باسمها في وثيقة المرحلة تحت قسم «ما لم يُتحقق بعد».

## 2. قواعد التوثيق والإصدارات

1. كل وثيقة تحمل رأسًا: الإصدار (vX.Y) + التاريخ (YYYY-MM-DD) + الحالة.
2. التعديل الجوهري يرفع الإصدار؛ التصحيح الطفيف يرفع العشري. **لا يُحذف المحتوى المعتمد — يُشطب بسبب موثق.**
3. تواريخ الوثائق بتوقيت القاهرة (Africa/Cairo).
4. اللغة: عربية أساسًا بمصطلحات تقنية إنجليزية معيارية (قرار ADR-0003). README فقط ثنائي اللغة كاملًا.
5. تسمية الملفات: `phase-NN-<slug>.md` داخل مجلد المرحلة، أو `aws-audit.md` / `initial-screening.md` للوثائق الخاصة.

## 3. حدود الصلاحيات (مسموح/ممنوع) — نص تأسيسي ملزم

**مسموح:** إنشاء وصيانة هذا المستودع · فحص المستودع المرجعي **قراءةً فقط** · البحث على الإنترنت · الدراسات والتقارير والخطط · ملفات التوثيق والقرارات · رفع التوثيق إلى `main` في هذا المستودع.

**ممنوع دون موافقة مستقلة موثقة من المالك:** تعديل كود Alkemos الأصلي · تغيير مزودي AI في الإنتاج · تعديل إعدادات الخوادم أو قواعد البيانات · شراء خدمات أو تفعيل اشتراكات مدفوعة (بما فيها استدعاءات Bedrock مدفوعة) · بدء تدريب مكلف أو تنزيل أوزان ضخمة (يُستثنى: نماذج ≤35B مكمّمة لغرض تقييم ضمن ميزانية معتمدة) · نقل بيانات مستخدمين أو بيانات صحية خارج بيئاتها المصرح بها · ~~تحويل هذا المستودع إلى عام~~ (**نُفذ بأمر مالك مباشر 2026-11-22 — ADR-0006: المستودع عام، ولا يُعاد إلى خاص إلا بأمر جديد**) · حذف أو إعادة تعيين تاريخ `main`.

**قاعدة عدم التوقف:** أعمال البحث والتخطيط لا تتوقف بانتظار قرار يخص تنفيذًا مستقبليًا — يُبنى البحث على سيناريوهات وتُعلَّق النقاط التنفيذية في `DECISIONS.md`.

## 4. بروتوكول العمل والدفع

1. قبل أي جلسة: قراءة `STATE.md` ← ملف المرحلة ← هذا الملف.
2. قبل أي ادعاء عن المستودع المرجعي: `git fetch` والتحقق من HEAD (لا ذاكرة محادثة).
3. بعد كل دفعة إنجاز: مراجعة اتساق النتائج ← تسجيل القرارات (ADR عند الجوهرية) ← تحديث `STATE.md` وملف المرحلة (حالة التنفيذ) ← commit برسالة وصفية ← push إلى `main` (forward-only، لا force).
4. رسالة الالتزام تصف ما أُنجز فعلًا لا ما هو مخطط.
5. «دفعة واحدة = كوميت واحد = تحديث حالة» — انسجامًا مع قانون المرجع.

- لا أسرار أبدًا (انظر `SECURITY.md`) — بما في ذلك لقطات شاشة ومخرجات أوامر.

- أي فحص إنتاجي قراءة-فقط، ولو فشل يُوثق الفشل ولا يُعاد اجتهادًا يخاطر بالإنتاج.
