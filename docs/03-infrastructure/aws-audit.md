## 5. القيد الحاسم: SCP المنظمة

المنظمة الأم تمنع صراحةً: EC2 (كل المناطق)، RDS، Lambda، ECS، ECR، ElastiCache، OpenSearch، Cognito، Lightsail خارج (us-east-1 + eu-north-1). **معناه العملي: لا يمكن حاليًا تشغيل GPU على EC2 داخل هذا الحساب مهما كان الرصيد.**

**الخيارات الثلاثة (تُحسم في المرحلة 3 بقرار مالك D-3):**
1. رفع القيد مع مالك الحساب الإداري للمنظمة (إن كان المالك يعرفه/يملكه) — يفتح EC2/GPU داخل AWS بالرصيد.
2. **التجاوز:** استضافة الاستدلال الذاتي خارج AWS (RunPod/Vast.ai — الأرخص أصلًا وفق COST_MODEL) مع إبقاء AWS للLightsail الإنتاجي. **(الميل الأولي للخطة)** — قابلية النقل عمود ملكية أصيل.
3. Bedrock كطبقة انتقالية مدفوعة داخل القيد الحالي (بلا ملكية أوزان — يخالف روح المشروع لكنه يحل التوفر فورًا).

## 6. الأوامر المرجعية (لإعادة الفحص مستقبلًا — قراءة فقط)

```bash
# الهوية والمنطقة
aws sts get-caller-identity
# موارد Lightsail في منطقتنا
aws lightsail get-instances --region eu-north-1
# فهرس Bedrock في منطقتنا
aws bedrock list-foundation-models --region eu-north-1 --query 'modelSummaries[].[modelId,providerName]' --output table
# التكاليف الشهرية
aws ce get-cost-and-usage --time-period Start=YYYY-MM-01,End=YYYY-MM-DD \
  --granularity MONTHLY --metrics "UnblendedCost" --group-by Type=DIMENSION,Key=SERVICE
# (السكربت الكامل للفحص محفوظ خارج المستودع ويمكن إعادة توليده من هذا الملف)
```
