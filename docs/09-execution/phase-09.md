# المرحلة 9 — خطة التنفيذ والاستقلال

> إصدار: v0.9 (هيكل) · تاريخ: 2026-11-21 · **الحالة: 🟡 هيكل + سيناريوهات — تكتمل مع نتائج المراحل 1–8** · التبعيات: 1+2+3 (ثم تُحدَّث مع كل مرحلة)

## 1. الهدف

تحويل الخطة إلى برنامج تنفيذي مرتب: مهام مرتبة بالأولوية والتكلفة والمخاطر، بموارد ومؤشرات وشروط توقف، ومسار زمني معلن للتخلي التدريجي عن APIs الخارجية.

## 4. مؤشرات النجاح القابلة للقياس (KPIs)

1. **نسبة الحصة الذاتية** (طلبات/توكنات مخدومة ذاتيًا): هدف L2 = مهمة واحدة 100% · L3 = ≥60% إجمالًا.
2. **تعادل الجودة:** ≥95% على البطاريات الحرجة للمهام الموجهة ذاتيًا (ثلاثة أسابيع متتالية قبل أي توسيع).
3. **التكلفة لكل مليون توكن مخرجة:** مقيسة شهريًا ومقارنة بالبديل.
4. **التوفر:** P95 لزمن أول توكن ≤ الأصل الحالي للمهام الدفعية.
5. **قابلية النقل:** تمرين النقل يُنجز في يوم عمل واحد (كل 6 أشهر).
6. **صفر حوادث سلامة/خصوصية** (الهدف المطلق).

## 5. شروط التوقف أو تغيير الاتجاه (Stop conditions)

1. فشل مرشحين المرحلة 3–5 جميعًا في بطارية العربية <85% → إعادة فحص الخيار (ب) أو تمديد مرحلة البيانات.
2. تكلفة التشغيل الذاتي أثبتت >2× البديل المدفوع لثلاثة أشهر → تجميد التوسيع وإعادة حساب.
3. تعارض ترخيصي يمنع التدريب على مخرجات المصدر الأمثل → تغيير المصدر لا كسر القاعدة.
4. أي حادث إنتاجي (مهما صغر) من التكامل → تراجع فوري + مراجعة جذرية قبل استئناف.
5. قرار مالك صريح في أي وقت — موثق في ADR.

## 6. «متى نتوقف عن الاعتماد على API خارجي؟» (الإجابة التصميمية)

**ليس حدثًا واحدًا بل عتبة معلنة:** عندما تخدم النماذج الذاتية ≥90% من الطلب الفعلي، وتبقى الـAPIs الخارجية كاحتياط متعمد (لا كاعتماد) لمدة 6 أشهر مستقرة — عندئذٍ يُعلن L3 ويُدرس قرار L4 بنموذج أساسي خاص (بشروط جدواه في المرحلة 6).

## 7. المهام التفصيلية

1. ✅ هيكل الموجات + السيناريوهات + KPIs + شروط التوقف.
2. ⬜ تثبيت التقديرات الزمنية بأرقام الاستخدام (W1).
3. ⬜ لوحة متابعة شهرية في STATE.md (إنفاق + حصة ذاتية + جودة).
4. ⬜ مراجعة الخطة كل موجة منجزة (إصدار جديد من هذه الوثيقة).
