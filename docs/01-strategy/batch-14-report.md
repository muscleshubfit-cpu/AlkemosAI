# تقرير دفعة 14 — بنية قياس M2: إصلاحات الفحص الستة + إعادة تصحيح النتائج + إطلاق Jais-3-7B + عدّة Kaggle

> التاريخ: 2026-11-23 (UTC) · النطاق: بنية قياس وتجهيز وإطلاق قياس ضمن M2 النشطة — **لا تدريب أوزان ولا اختيار نموذج ولا توليد إنتاجي ولا أي التزام مالي ولا مساس بإنتاج Alkemos ولا تعديل أي ملف بيانات أو بطاقة أو بطارية قانونية أو نتيجة موقعة**.
> التفويض: المراجعة النوعية §7 («توصيات مُلزمة قبل تشغيل البطارية الكاملة 162 — لا تتطلب قرار مالك — بنية قياس») + تقرير الاكتشاف §5.2 (أولوية Jais-3-7B وقناة GHA للفئة ≤12B) + دراسة الموارد (Kaggle للفئة 20B+) — كلها ضمن D-11/ADR-0022 الساريتين.

## 1. ما الذي استُكمل ولماذا الآن (بلا GPU وبلا انتظار Kaggle)

أربعة أعمال كانت كلها ممكنة التنفيذ الفوري وشكّلت معًا استثمارًا كاملًا لفترة الانتظار:

1. **إصلاحات الفحص الستة الملزمة** (المراجعة النوعية §7) — شرط مسبق لكل تشغيل قادم (162 الكاملة للمختصرين) وعمل كود CPU خالص.
2. **إعادة تصحيح النتائج الخمس الموقعة** — النصوص الكاملة محفوظة كأدلة في ملفات النتائج، فتطبيق الفحوص المصححة عليها لا يحتاج أي توليد — يقوّم مصفوفة أدلة D-5 فورًا.
3. **إطلاق قياس Jais-3-7B (الأولوية الأولى لفجوة العربية الأصيلة)** — فئة ≤12B تعمل على GHA CPU مباشرة (السير مبني لهذا أصلًا — مدخله المثالي الموثق في تعريفه هو `Jais-3-7B-Q4_K_M`) — لا يستهلك حصة Kaggle ولا ينتظرها.
4. **تجهيز عدّة Kaggle للفئة 20B+** — بحيث يبدأ القياس فور التجديد 2026-11-28 بلا دقيقة تجهيز تُهدر من الحصة (تخفيف R-41).
