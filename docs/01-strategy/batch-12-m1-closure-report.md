## 2. فتح M2 باكتشاف مفتوح (ADR-0022)

- أمر المالك (2026-11-22 UTC): اكتشاف مرشحين بلا قائمة مسبقة ولا حصر في عائلات محددة، بالقدرات الست والأحجام الثلاثة، واختبار الأفضل على البطارية، وكل استبعاد موثق السبب، ولوحات التقييم العامة مؤشر فرز لا حكم نهائي — موثق كـ**ADR-0022** (وهو «القرار الموثق» الذي يفتح به باب تغيير القائمة وفق قانون ADR-0021 ق5).
- تسلسل المسار م ثابت: **M1 ✅ ← M2 (نشطة الآن) ← D-5 ← M3 ← M4** — لا تدريب أوزان قبل حسم D-5.
- خطة M2 التنفيذية: (1) اكتشاف شامل (HF API مقيس + مصادر مستقلة بتواريخ اطلاع) → (2) مصفوفة مرشحين بأدلة الإدراج/الاستبعاد → (3) قائمة مختصرة → (4) قياس فعلي على البطارية بعينة طبقية موثقة + مجسات أبعاد المدرب (مصرية/حوار/تقدم/أدوات) → (5) نتائج موقعة في `evaluation/results/` → (6) توصية مبررة لـD-5 (قرار المالك) — كل ذلك في القنوات المجانية حصرًا (CPU محلي + قناة API مجانية + GHA للمستودع العام + Kaggle المفعلة).
