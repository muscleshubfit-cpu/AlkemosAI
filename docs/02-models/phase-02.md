# المرحلة 2 — دراسة النماذج المفتوحة

> إصدار: v0.9 (مبدوءة) · تاريخ: 2026-11-22 · **الحالة: 🟡 الفرز الأولي منجز — التقييم العملي معلق على قرار الميزانية D-2** · التبعيات: المرحلة 0 ✅ (التقييم العملي يفتح بعد G1)

## 1. الهدف

ترتيب أفضل النماذج المفتوحة المرشحة لتخصصاتنا (عربية+إنجليزية، لياقة/تغذية/صحة، اتباع تعليمات، JSON صارم) مع بدائل احتياطية، بعد فحص التراخيص من مصادرها، ودراسة التكميم وMoE والتقطير.

## 2. معايير الفرز (مرتبة)

1. **الترخيص أولًا:** يسمح بالاستخدام التجاري + التعديل + التدريب على المخرجات (للتقطير) — بلا قيود إيرادات أو مجالات.
2. جودة العربية الفطرية (لا عبر ترجمة) — تُقاس على مهامنا.
3. جودة الإنجليزية والالتزام بالتعليمات وJSON الصارم (متطلب مهام خطط/أدوات خط الأساس).
4. الحجم والتكميم: قابل للتشغيل بـ 24–48GB VRAM (طبقة التقييم) وصولًا إلى 80GB (طبقة الجودة).
5. نضج الأدوات: vLLM/llama.cpp/Unsloth + مجتمع نشط.
6. توفر نسخة base (لتابع التدريب لاحقًا) وليس instruct فقط.

## 4. دراسة التقنيات (خلاصة أولية — تُعمّق عند التنفيذ)

- **التكميم (GGUF/AWQ/GPTQ):** يخفض التشغيل من 80GB إلى 24GB بفقد جودة طفيف معمومًا [موثق من مصادر عامة 2026] — إلزامي لخطة الـ$0.34/ساعة.
- **MoE:** معماريات A3B (3B نشطة) تمنح سرعة كبيرة بسعر صغير — مثالية للمهام المتوسطة؛ الحجم الكامل يستهلك ذاكرة كثيفة.
- **BitNet/1.58-bit:** واعدة نظريًا (تشغيل CPU) لكن نضجها الإنتاجي غير مثبت [غير متحقق] — تراقب دون اعتماد.
- **التقطير:** من نموذج كبير مدفوع إلى مرشحنا المفتوح — **محظور ترخيصيًا مع بعض المزودين**؛ يدرس مشروطًا بتراخيص المصدر (بند صريح في كل تقييم).

## 5. خطة التقييم العملي (بعد اعتماد الميزانية D-2)

```bash
# (أوامر مرجعية تُنفَّذ عند فتح المرحلة — ليست للتنفيذ الآن)
# 1) استئجار RTX 4090 على RunPod Community ($0.34/ساعة — سعر 2026-11-12)
# 2) تشغيل المرشح عبر vLLM (واجهة متوافقة مع OpenAI):
docker run --gpus all -p 8000:8000 vllm/vllm-openai \
  --model Qwen/Qwen3.5-35B-A3B-Instruct --max-model-len 16384
# 3) تشغيل بطارية مهامنا (المرحلة 7) ضد النقطة النهائية:
python eval/run_suite.py --base-url http://<gpu>:8000/v1 \
  --suite suites/fitness-ar.jsonl suites/plans-json.jsonl
# 4) نفس البطارية على llama.cpp بكمّ Q4_K_M لقياس الفرق
```

**معيار النجاح:** 3–5 نماذج مقيمة على مهامنا الفعلية (عربية/إنجليزية/JSON/أرقام) بترتيب موثق + بديلان احتياطيان + قرار ترخيص موثق لكل معتمد.

## 6. المهام التفصيلية

1. ✅ الفرز الأولي بمصادر مؤرخة (هذه الوثيقة + initial-screening).
2. ⬜ تحقق مباشر من ملف LICENSE لكل مرشح نهائي (تنزيل النص من المستودع — لا الاكتفاء بوصف البطاقة).
3. ⬜ بناء بطارية تقييم مصغرة (50 حالة × 2 لغة) من حالات إنتاج حقيقية منزوعة الهوية.
4. ⬜ التقييم العملي على GPU مؤجرة (الأمر أعلاه) + جدول نتائج موثق.
5. ⬜ قياس التكميم: الجودة والسرعة عند Q4_K_M مقابل FP8.
6. ⬜ توصية نهائية: نموذج «المهام المنضبطة» + نموذج «المهام العميقة» + احتياطيان.
