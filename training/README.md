# training/ — الطبقة ج: إعدادات ومخرجات دفعات التدريب

هذا المجلد سيحمل **إعدادات جولات التدريب وتقاريرها** (يُنشأ محتواه عند بدء M3 — بعد اعتماد الخطة v2.0 وتجاوز M1/M2).

## ما سيعيش هنا (من `PLAN.md` §4.2 و§7)

- إعدادات كل دفعة: النموذج الأساس + إصدار البيانات + معاملات QLoRA + نقاط الحفظ (قابلة للاستئناف — الجلسات على Kaggle متقطعة بالتصميم: ADR-0010).
- تقارير الدفعات: الخسائر، زمن الجولة، قرار بوابة G-Q (قبول/رفض مع السبب).
- عناصر الإعادة (replay) المعتمدة لمنع النسيان.

## ما لا يعيش هنا

- **الأوزان نفسها** (المحولات/GGUF): في التخزين الثلاثي (HF خاص + GitHub Releases + نسخة محلية) — وروابطها وSHA256 في `registry/` (ADR-0009).
- بيانات التدريب: في `datasets/`. بطاريات التقييم: في `evaluation/`.

## البيئات المعتمدة

Kaggle أساسًا (30 GPU-س/أسبوع) · Colab احتياطًا · GHA ‏CPU للتحضير — كلها مجانية بلا بطاقة (ADR-0010).
