# research/ — خط الدخول: رصد المصدر الأساسي والبحث الخارجي (مرشحون فقط)

هذا المجلد يحمل **منظومتي الدخول المنضبطتين** لكل مادة جديدة: **المراقب** (اكتشاف تلقائي لتغييرات المستودع الأساسي) و**البحث الخارجي** (وصول مستقل قابل للتطوير إلى مصادر الإنترنت) — وكل مخرجاتهما **مرشحة** لا تُعتمد معرفةً إلا عبر بوابة G-K (ADR-0012/0016/0017).

## البنية

```
research/
  source-watch/          # المراقب: ملخصات تغييرات alkemos-aws (digests) + state.json (آخر SHA + طوابع UTC)
  external/              # البحث الخارجي: عمليات البحث الموثقة (runs) — كل نتيجة برابطها وتاريخ اطلاعها وموثوقيتها
  backlog.md             # قائمة أسئلة البحث المفتوحة (فجوات معرفة + أسئلة المالك + احتياجات SEO/GEO/AEO)
```

## قواعد المراقب (ADR-0012)

1. **قراءة-فقط دائمًا** عبر GitHub API العام — لا كتابة إلى أي مستودع أو نظام تابع لـAlkemos.
2. إيقاع معلن (تقدير البدء: كل 6 ساعات UTC): مقارنة HEAD بآخر SHA مُشاهد → **digest لكل دفعة commits** (SHA، الطابع UTC، الملفات، وسوم معرفي/غير معرفي).
3. المسارات المعرفية فقط تدخل `memory/inbox/`: `src/lib/**` المعرفية · `docs/**/*.md` · `supabase/migrations/**` · ملفات الحوكمة العليا.
4. لقطات المحتوى اليومية (musclehubeg-backups): **جداول المحتوى فقط** بقائمة بيضاء (blog_posts، nutrient_reference، recipes*، evo_nutrition_patterns — تأكيد D-15) — بلا أي PII إطلاقًا.

## قواعد البحث الخارجي (ADR-0016)

1. **الفصل الصارم:** الجمع/البحث ≠ الاعتماد — النتائج «مرشحة» في صناديق المراجعة، والاعتماد عبر G-K فقط (لا اعتماد تلقائي أبدًا).
2. **مصادر مصرح بها فقط:** واجهات/صفحات عامة رسمية (لا scraping مخالف لشروط الاستخدام)؛ لا مفاتيح في سير عمل عام (R-35).
3. **مقارنة وتصديق:** كل ادعاء جوهري بمصدرين مستقلين على الأقل + تصنيف موثوقية وفق القائمة البيضاء (الجهات الـ14 + .gov/.int/.edu + محكم الأقران) — ما دون الحد يُوسم «غير موثوق» ويبقى مرجعًا لا مصدر اعتماد.
4. **تسجيل كامل:** لكل مصدر: الرابط + تاريخ الاطلاع (UTC — ADR-0013) + الاقتباس أو هاشه + درجة الموثوقية — قابل للتفتيش الكامل.
5. **حدود التخزين:** اقتباس + هاش افتراضيًا؛ لا صفحات كاملة إلا بما يجيزه ترخيص المصدر؛ لا بيانات مستخدمين إطلاقًا (SECURITY §8).
