# ملاحظات المالك والمدربين — صندوق المراجعة الأول

> أحد صناديق المراجعة الثلاثة (memory/inbox/README). كل ما يكتب هنا **«مرشح»** — يعتمد عبر بوابة G-K فقط (مصدر موثق + لا تعارض غير محلول + إثبات إضافة + ثنائي اللغة + توقيع UTC).

## طريقة الاستخدام

أضف أي ملاحظة بالصيغة التالية (التاريخ UTC — ADR-0013):

```markdown
## ملاحظة — YYYY-MM-DD (UTC)
- **الموضوع:** …
- **المصدر (إن وجد):** رابط/SHA + تاريخ اطلاع UTC
- **الحالة:** مرشحة للمراجعة في دورة G-K القادمة
```

- *لا ملاحظات بعد — أول ملاحظة تُوثق هنا وتدخل أول دورة G-K في M1.*
