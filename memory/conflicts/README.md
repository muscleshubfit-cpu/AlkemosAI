# memory/conflicts/ — قائمة قرار التعارضات

> أُنشئ بدفعة 6 (2026-11-21 UTC). قانون ADR-0017: كشف التعارض إلزامي عند كل اعتماد — لا كتابة صامتة فوق معرفة قائمة.

## صيغة قيد التعارض

```markdown
---
conflict: CONFLICT-<رقم>
opened: <YYYY-MM-DD> (UTC)
entities: <الكيان/الحقل المتعارض عليه>
cards: [<ids البطاقات المتعارضة>]
---
- **القيمة القائمة:** <…> — بطاقة `<id>` (مصدرها: …)
- **القيمة الجديدة:** <…> — مرشح من <الصندوق/المصدر>
- **أساس الحسم:** الموثوقية ثم التوثيق ثم الأحدث (ADR-0017 ق6.2)
- **القرار:** <معلق | حُسم لصالح … بتاريخ UTC — الخاسر شُطب وأُرشف بسبب: …>
```

## القيود

- **لا تعارضات معلقة حاليًا** — أول دورة G-K (دفعة 9، 2026-11-22 UTC): فحص التعارض نُفذ آليًا على مفتاح `entity` (كيان/حقل — ADR-0017 ق2) لكل بطاقات العينة الـ15 وداخلها وبينها وبين القائمة (كانت صفرًا يومها): **صفر تعارض وصفر تكرار** (اختبار طفرة 10/10 — `scripts/test_gk_gate_mutations.py` يثبت أن الكيان المكرر بقيمة مختلفة والقيمة المطابقة تحت معرف جديد كلاهما يُلتقط ويُخفق البناء).
- كل تعارض يُفتح ويُحسم في نفس دفعة الاعتماد المتعلقة به إن أمكن؛ المعلق يُراجع في أول دفعة تالية.
