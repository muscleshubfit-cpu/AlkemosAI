# memory/ — الطبقة ب: الذاكرة المملوكة

هذا المجلد يحمل **ذاكرة المشروع**: ما يعرفه ويتعلمه خارج الأوزان — أرخص طبقات التراكم وأسرعها نموًا (لا تحتاج GPU).

## البنية المستهدفة (من `PLAN.md` §6 — v2: ADR-0017)

```
memory/
  cards/            # بطاقات المعرفة v2: إصدار + آخر مراجعة (UTC) + حالة + superseded-by + contradicts + أصل كامل
  learning-log.md   # سجل التعلم: كل اعتماد (معرفة/مهارة/أوزان) — بياناته، نتائجه، ما أُضيف، ما رُفض ولماذا
  inbox/            # صناديق المراجعة الخام (دفعة 4): ملاحظات المالك + digests مراقب المصدر الأساسي + مرشحو البحث الخارجي
  conflicts/        # قائمة القرار للتعارضات غير المحسومة
  archive/          # البطاقات المشطوبة (مؤرشفة بتاريخها وسببها — لا حذف أبدًا)
```

## القواعد

1. **بطاقة المعرفة** بصيغة موحدة: العنوان، التصنيف، الحقائق، المصدر، تاريخ آخر مراجعة، الحالة (مسودة/معتمدة).
2. **سجل التعلم هو «ضمير التراكم»** — يُحدَّث إلزاميًا في نفس دفعة كل نتيجة تعلم (قبولًا أو رفضًا).
3. **الفهرس مشتق دائمًا:** أي فهرسة متجهة (pgvector/Vectorize/bge-m3) طبقة قابلة لإعادة البناء من هذه الملفات بأمر واحد — تغيير نموذج التضمين = إعادة فهرسة، لا هجرة بيانات (ADR-0009).
4. لا PII ولا بيانات مستخدمين — معرفة تخصصية فقط.
5. **(دفعة 4 — ADR-0017) كشف التعارض إلزامي عند كل اعتماد:** قيمة جديدة تخالف قائمة → علامة تعارض + قائمة قرار — لا كتابة صامتة فوق معرفة قائمة؛ الحسم بالموثوقية والتوثيق والأحدث؛ الخاسر يُشطب بسبب موثق ويُؤرشف (لا حذف).
6. **(دفعة 4) بوابة G-K لكل دخول معرفة:** مصدر موثق + لا تعارض غير محلول + إثبات إضافة مقيسة + فحص ثنائي اللغة (AR/EN) + توقيع بتاريخ UTC — النتائج تُسجل في سجل التعلم.
7. **(دفعة 4) مصادر الصناديق الثلاثة:** ملاحظات المالك/المدربين · ملخصات مراقب المصدر الأساسي (ADR-0012) · مرشحو البحث الخارجي (ADR-0016) — كلها «مرشحة» حتى تعبر G-K.
