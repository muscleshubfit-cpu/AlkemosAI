## القواعد

1. **لا بطاقة تعتمد إلا عبر بوابة G-K** (مصدر موثق + لا تعارض غير محلول + إثبات إضافة مقيسة + فحص ثنائي اللغة AR/EN + توقيع بتاريخ UTC).
2. **كشف التعارض إلزامي:** قيمة تخالف بطاقة قائمة → علامة تعارض + قيد في [`../conflicts/`](../conflicts/) — **لا كتابة صامتة فوق معرفة قائمة**؛ الخاسر يُشطب بسبب موثق ويُؤرشف.
3. **لا حذف أبدًا:** البطاقة المشطوبة تُنقل إلى [`../archive/`](../archive/) بتاريخها وسببها.
4. الحالة الآن: **لا بطاقات بعد** — أول بطاقات المعرفة تُنتج ضمن دورات G-K الأولى في M1.
