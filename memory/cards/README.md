## القواعد

(دفعة 9: الفحص مُأسس آليًا على مفتاح `entity` — مولّد الدورة يخفق عند أي كيان مكرر بقيمة مختلفة أو تكرار مطابق تحت معرف جديد.) 3. **لا حذف أبدًا:** البطاقة المشطوبة تُنقل إلى [`../archive/`](../archive/) بتاريخها وسببها.
