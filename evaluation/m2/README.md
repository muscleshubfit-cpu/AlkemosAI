# evaluation/m2/ — أصول تقييم M2 (دفعة 13 — ADR-0022)

> **حالة هذه الملفات:** مجسات تقييم خاصة بـ**M2 (اختيار الأساس)** تغطي أبعاد أداء المدرب غير المغطاة بعد في البطارية القانونية v0 (مواصفة البطارية §6) — **ليست جزءًا من `alkemos-eval-v0.jsonl` القانوني ولا تدخل بيانات التدريب أبدًا** (قانون الفصل الصارم). دمجها الرسمي كمجموعات بطارية موقعة يحدث لاحقًا وفق «قانون نمو البطارية قبل التدريب» قبل تدريب كل مجال منها.

## المنهجية (تقرير M2)

- كل مجس يحمل `auto_check` (فحوص آلية: أرقام بكلمات مفتاحية أو نمط) + `rubric` (معيار الحكم النوعي الذي يقيّم به الوكيل المخرجات مع النصوص الكاملة محفوظة كأدلة في `results/m2/`).
- الأرقام المرجعية في المجسات محسوبة بمعادلات المنصة نفسها (Mifflin-St Jeor ومعاملاتها · 30/40/30 · 35 مل/كغ بقيد 2000–4500 — بطاقات CARD-0001..0007) — مذكورة في حقل `note` لكل مجس.
- أصل صياغة المهام: أنماط مهام المنصة الحقيقية (أدوات ai-job وأنماط أسئلة EVO) مع إعادة صياغة لغوية للمصرية وسيناريوهات المتابعة — **صناعة الوكيل لغرض قياس M2 [تقدير موثق]**، لا حالات منقولة من المصدر الأساسي؛ لذا تبقى خارج البطارية القانونية حتى إنتاج رسمي لاحق عبر المولّد الحتمي.
