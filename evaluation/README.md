# evaluation/ — بطارية التقييم وبوابات الجودة

هذا المجلد يحمل **الحكم الوحيد على أي تعلم**: بطارية تقييم ثنائية اللغة مبنية من مهام Alkemos الحقيقية، ونتائجها الموقعة.

## البنية المستهدفة (من `PLAN.md` §7.2)

```
evaluation/
  alkemos-eval-v0.spec.md  # مواصفة البطارية v0 — عقد البناء (أُنشئ بدفعة 6)
  alkemos-eval-v0.jsonl    # 162 حالة من مهام المنصة الحقيقية (أُنتجت بدفعة 8 — 2026-11-22 UTC)
  results/                 # نتائج موقعة لكل دفعة/نموذج (تُحفظ مع تقريرها)
```

## القواعد الملزمة

1. **المنشأ:** حالات من المهام الإنتاجية الحقيقية — أدوات `ai-job` العشرة، أسئلة EVO النمطية، قيود الخطط (±20% سعرات، مطابقة مكتبة التمارين)، قواعد دستور التحرير (استشهاد من الجهات الـ14 البيضاء فقط، لا لاتيني في العربية…).
2. **الفصل الصارم:** لا تدخل أي حالة من البطارية في بيانات التدريب أبدًا.
3. **بوابة G-Q:** قبول أي محول جديد = صفر انحدار >1% على المجموعة الحرجة (العربية/الأرقام/السلامة) + تحسن مقيس على مهام الدفعة — النتائج تُوقَّع وتُحفظ هنا.
4. **التشغيل:** آليًا على GHA (نماذج ≤2B مكمّمة GGUF عبر llama.cpp) أو ضمن جلسة Kaggle نفسها.
5. تنمو البطارية مع كل مجال جديد **قبل** تدريبه.
