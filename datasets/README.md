# datasets/ — الطبقة أ: المعرفة والبيانات المملوكة

هذا المجلد يحمل **مادة التعلم** الخاصة بالنموذج: أمثلة تدريب وصيغ معرفة موثقة المصدر والترخيص، مرقمة الإصدارات.

## القواعد الملزمة (من `PLAN.md` §5)

1. **الصيغ:** JSONL لأمثلة التدريب (SFT ولاحقًا أزواج تفضيل DPO) + بطاقات Markdown للمعرفة الخام.
2. **الترخيص:** كل ملف/مصدر يُسجل في `LICENSE-LOG.md` داخل كل إصدار — قائمة البيضاء فقط (ملك Alkemos · Unlicense/ملك عام · Apache-2.0 · MIT · CC-BY).
3. **الإصدارات:** كل دفعة تعلم تستهلك إصدار بيانات محدد `vX.Y` مع `CHANGELOG.md` — لا تعديل على إصدار منشور أبدًا (يُنشأ إصدار جديد).
4. **الوسم:** كل مثال يحمل `source:` (مثلاً `alkemos:exercises` أو `synthetic:groq:2026-12-01`) — القابلية للتفتيش الكامل.
5. **الأرقام:** أي أرقام حساسة (سعرات/ماكروز) تُحقن كحقول إلزامية من البيانات المنظمة — لا من ذاكرة النموذج (قانون موروث من خط الأساس).
6. **ممنوعات:** لا بيانات مستخدمين ولا PII إطلاقًا (SECURITY.md §3). بطارية التقييم تعيش في `evaluation/` ولا تدخل هنا أبدًا.
7. **(دفعة 4 — ADR-0012/0017):** أي بيانات من المصدر الأساسي alkemos-aws تُوثق بـSHA الالتزام وتاريخ الاطلاع (UTC)؛ المراقب يغذي صناديق المراجعة، ولا يعتمد شيء إلا عبر بوابة G-K (تعارض + مصدر + إثبات إضافة + فحص ثنائي اللغة).
8. **(دفعة 5):** حقوق كل أصل (المنبع/الترخيص/أساس الحق/الفارق المملوك) موثقة في [`../references/data-rights.md`](../references/data-rights.md) — لا يوصف أصل بأنه «ملك حصري» إلا بأساس موثق هناك.
