# ADR-0016 — خط البحث الخارجي المستقل: فصل صارم بين جمع المعلومات واعتمادها معرفة

> الحالة: مقبول (ضمن حزمة v2.1 — التنفيذ ضمن C2 بعد اعتماد D-11) · التاريخ: 2026-11-21 (UTC) · صاحب القرار: وكيل الدفعة 4 (تصميم) بتوجيه مالك — الاعتماد النهائي للمالك

## السياق

1. توجيه المالك (دفعة 4): «بناء قدرة بحث مستقلة وقابلة للتطوير للوصول إلى مصادر الإنترنت، واكتشاف المعلومات الحديثة وجمعها ومقارنتها والتحقق من موثوقيتها وتسجيل مصادرها، ثم تحويل النتائج الموثوقة إلى معرفة قابلة للتراكم والتعلم. **افصل بين البحث وجمع المعلومات وبين اعتمادها كمعرفة**».
2. الموارد المجانية الموثقة للجمع بلا أي التزام: GitHub Actions (حوسبة دفعية للمستودع العام) + وصول مباشر مجاني إلى واجهات عامة رسمية بلا مفاتيح (PubMed/arXiv/Wikipedia/مواقع الجهات العلمية) [موثق]؛ طبقة Tavily المجانية (1,000 رصيد/شهر بلا بطاقة [موثق — sources-log §4]) خيار لحساب جديد مستقل [غير متحقق — يُثبت عند التنفيذ]؛ أداة `Agent-Reach` (fork مملوك للمالك، MIT) مرشح أدوات [غير متحقق التقييم بعد].
3. خط الأساس يمنع مسبقًا الاعتماد غير الموثق: دستور التحرير يقيد الاستشهاد بـ14 جهة علمية بيضاء، وقانون «لا إدخال بلا دليل» قائم.

## القرار

1. **خط بحث خارجي (`research/`)** بخمس مراحل منضبطة:
   1. **اكتشاف:** قائمة أسئلة بحث (`research/backlog.md`) من فجوات المعرفة المكتشفة + أسئلة المالك + احتياجات مسار SEO/GEO/AEO.
   2. **جمع:** طلبات قراءة من مصادر مصرح بها فقط (واجهات/صفحات عامة رسمية؛ لا انتهاك شروط استخدام؛ لا scraping مخالف).
   3. **مقارنة وتصديق:** كل ادعاء جوهري بمصدرين مستقلين على الأقل + تصنيف موثوقية وفق قائمة بيضاء (الجهات الـ14 + نطاقات .gov/.int/.edu + المحكم بالأقران) — ما لا يبلغ الحد يُوسم «غير موثوق» ويبقى مرجعًا لا مصدر اعتماد.
   4. **تسجيل:** سجل كامل لكل عملية (`research/external/runs/`): الروابط، تاريخ الاطلاع (UTC)، الاقتباس أو هاشه، درجة الموثوقية — قابل للتفتيش الكامل.
   5. **مرشحون فقط:** نتائج البحث تسكن `inbox/research/` بحالة «مرشحة» — **لا تدخل المعرفة ولا البيانات إلا عبر بوابة G-K** (ADR-0017: توثيق مصدر + فحص تعارض + مراجعة عينة ثنائية اللغة + إثبات إضافة مقيسة قبل الاعتماد).
2. **الحدود:** لا بيانات مستخدمين؛ لا تخزين صفحات كاملة إلا بما يجيزه ترخيص المصدر (اقتباس+هاش افتراضيًا)؛ لا مفاتيح في سير عمل عام؛ نطاق المصادر مصرح به في تعريف السير (R-35).
3. **قابلية التطوير:** الخط يعمل بالتوازي مع المراقب (ADR-0012) — الاكتشاف الآلي للمصدر الأساسي + البحث الخارجي يغذيان صندوق المراجعة نفسه وبوابات الاعتماد نفسها، فيتوسع البحث بإضافة مصادر/أسئلة لا بإعادة تصميم.

## الخيارات التي فُحصت

- **بحث بلا فصل عن الاعتماد** (إدخال مباشر للمعرفة): مرفوض — نص التوجيه الصريح، ويهدم قانون «لا إدخال بلا دليل».
- **بحث عبر مزودي الإنتاج الحاليين** (Exa/Tavily بحسابات Alkemos): مرفوض — يقترن المسار الحرج بإنتاج Alkemos ومزوديه (محظور)؛ حسابات جديدة مستقلة فقط عند الحاجة وبقرار موثق.

## النتائج

- C2 في خارطة الطريق؛ `research/README.md` يوثق البنية؛ المخاطر R-30/R-35 تُسجل؛ SECURITY §8 (قواعد خصوصية البحث والرصد).
- «معلومات حديثة» تصبح قابلة للتراكم فقط بعد التصديق — الذاكرة لا تتلوث بمجرد البحث.
