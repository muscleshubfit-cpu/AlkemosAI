# ADR-0006 — تحويل المستودع إلى عام واعتماد المسار الصفري (مجاني 100%) كمسار التنفيذ النشط

> الحالة: مقبول (بأمر مالك مباشر 2026-11-21) · التاريخ: 2026-11-21 · صاحب القرار: **المالك** (توجيه مباشر) · التوثيق: وكيل التنفيذ

## السياق
1. أمر المالك المؤرخ 2026-11-21 نص صراحة على: تحويل مستودع AlkemosAI من خاص إلى عام، ثم البحث عن حلول مجانية تمامًا (بلا اشتراكات/مدفوعات/بطاقة بنكية/تجارب مؤقتة) لبناء وتشغيل منظومة الذكاء الاصطناعي المستقلة، مع استغلال موارد AWS القائمة دون إضافة تكاليف، واعتماد البدائل مفتوحة المصدر القابلة للاستضافة الذاتية، وألا يُفترض أي حل قبل فحص المشروع الفعلي.
2. SECURITY.md §4 كانت تقيد التحويل إلى عام بأمر مالك صريح — وقد صدر الأمر.
3. DECISIONS.md ‏D-2 (مستوى الميزانية) كانت معلقة على المالك بأربعة سيناريوهات (صفر/منخفض/متوسط/عالٍ).

## القرار
1. **المستودع عام (PUBLIC) من 2026-11-21** — نُفذ عبر GitHub API وتحقق (`visibility: public`). النتائج المرتبطة:
   - GitHub Actions على المشغّلات القياسية تصبح **مجانية بلا حد للدقائق** — أصبحت الحوسبة الدفعية الأساسية للمشروع (نفس النمط الذي يعمل به إنتاج Alkemos). *(تحديث دفعة 5: «بلا حد» خاص بالمستودعات العامة — بعد التحول إلى خاص (T1) يصبح السقف 2,000 دقيقة/شهر بالخطة المجانية، والتعلم يستمر وفق ADR-0019 §6.)*
   - الالتزام الأمني يتصاعد: كل الملفات وسجلات التشغيل مكشوفة — قاعدة «لا أسرار أبدًا» نافذة بصرامة مضاعفة، والمفاتيح في GitHub Secrets فقط.
2. **اعتماد المسار الصفري كمسار التنفيذ النشط** — سيناريو «صفر» في COST_MODEL ‏§4 يُرفع من «تخطيط فقط — لا استقلال» إلى مسار تنفيذ كامل بنتائج ملكية حقيقية، مفصّلًا في `ZERO_COST_PLAN.md` (خطة F0–F5): ملكية معرفة/ذاكرة فورية، نموذج مملوك يُدرَّب مجانًا (Kaggle)، واستضافة ذاتية مجانية للمهام الدفعية (HF Space ‏CPU + llama.cpp)، وقابلية نقل كاملة بين الاستضافات.
3. **AWS تُحمَل ولا تُوسَّع** — لا مورد AWS جديد في هذا المسار؛ الإنتاج القائم لا يُلمس (R-06)؛ Bedrock/GPU مؤجر خارج المسار الحالي.

## الخيارات التي فُحصت (وانظر ZERO_COST_PLAN §3.2)
- البقاء على خاص + GHA بـ2000 دقيقة/شهر: مرفوض — يخنق خطوط التوليد التركيبي والتقييم الآلي التي يقوم عليها المسار، والمالك أمر بالتحويل.
- المواقع المجانية المتطلبة بطاقة (Oracle Always Free وأمثالها): مستبعدة بشرط المالك الصريح.
- أرصدة تأسيسية مؤقتة (Lightning AI وأمثالها): مستبعدة — نمط تجربة ينتهي.

## النتائج
- دقائق الحوسبة الدفعية لم تعد موردًا نادرًا — عنق الزجاجة ينتقل إلى جودة البيانات العربية وقياس النماذج الصغيرة.
- D-2 في DECISIONS.md تُحدَّث إلى «محسومة للمرحلة الحالية: صفر — بأمر مالك 2026-11-21»، مع بقاء السيناريوهات الأعلى موثقة لباب مستقبلي بقرار جديد.
- تُضاف قرارات المالك الجديدة D-9 (عتاد المالك) وD-10 (اعتماد بدء F0) إلى قائمة DECISIONS.md.
- RISK_REGISTER تُستكمل بمخاطر المسار الصفري (ZERO_COST_PLAN §9) عند أول مراجعة دفعة.
