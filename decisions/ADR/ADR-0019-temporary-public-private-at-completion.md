# ADR-0019 — الملكية والاستضافة: حقوق الأساس مقابل ملكيتنا، والعلنية المؤقتة بتحول إلى خاص عند الاكتمال

> الحالة: مقبول (العلنية الحالية سارية؛ التحول إلى خاص مؤجل إلى T1 بقرار D-14) · التاريخ: 2026-11-22 (UTC) · صاحب القرار: **المالك** (توجيه دفعة 4) — التوثيق: وكيل الدفعة 4

## السياق

1. توجيه المالك (دفعة 4): «الحفاظ على قابلية نقل البيانات والذاكرة والمهارات والأوزان بين الاستضافات، وتوضيح حقوق نموذج الأساس مقابل ملكية بياناتنا ومحولاتنا. **المستودع عام مؤقتًا للمراجعة فقط، ويجب تضمين تحويله إلى خاص عند اكتمال المشروع**».
2. ADR-0006 جعل المستودع عامًا لأسباب تشغيلية (دقائق GHA المجانية للمستودعات العامة) بلا غاية ختامية موثقة.
3. سلوك GitHub الموثق عند التحويل عام→خاص: **الـforks العامة القائمة تبقى عامة في شبكة منفصلة**، وقد تتأثر stars/watchers وبطاقات الرسم البياني [موثق — توثيق GitHub الرسمي «Setting repository visibility»، اطلاع 2026-11-22 — `references/sources-log.md` §7].

## القرار

1. **تصنيف الملكية (موثق تفصيلًا في `PLAN.md` §8):**

   | الأصل | الملكية/الحقوق |
   |---|---|
   | نموذج الأساس (Apache-2.0/MIT — ADR-0011) | مفتوح من مزوده: يمنحنا التعديل والتوزيع والاستخدام التجاري مع حفظ إشعاراته؛ وسماته وأسماؤه التجارية ملك أصحابها |
   | بياناتنا/ذاكرتنا/مهاراتنا/محولاتنا/سجلات التعلم | **ملك حصري لنا** — الفارق المُتعلم كله؛ ترخيص نشرها الخارجي يقرر عند التحول (D-14) |

2. **النقل (موروث ADR-0009 + توسيع):** البيانات والذاكرة والمهارات والسجلات = ملفات المستودع (تنقل باستنساخه)؛ الأوزان = التخزين الثلاثي؛ عقد إعادة البناء يشمل الطبقة د (المهارات). **لا أصل مملوك يسكن موقعًا واحدًا أبدًا.**
3. **العلنية مؤقتة للمراجعة فقط:** أسبابها التشغيلية (GHA) سارية خلال البناء؛ وتوثَّق غايتها الختامية الآن: **التحول إلى خاص عند اكتمال المشروع**.
4. **بروتوكول التحول (T1 — خارطة الطريق) بقرار D-14 (يحدد لحظة «الاكتمال»):** قائمة الفحص قبل التحويل: (أ) مسح أسرار نهائي للكود والتاريخ؛ (ب) تدوير كل مفتاح شُرك في محادثات الوكلاء (توصية قائمة — R-32)؛ (ج) قبول أثر الـforks العامة الباقية عامة (توثيق GitHub) — ومنه **القاعدة منذ الآن: لا يوضع في العلني ما لا يصح بقاؤه عامًا أبدًا**؛ (د) أرشفة أصول خارج GitHub إن لزم؛ (هـ) تنفيذ التحويل عبر GitHub API وتوثيقه في STATE/ADR.
5. **أثر مفهوم لاحقًا:** بعد التحول تنخفض دقائق GHA المجانية (المستودعات الخاصة: 2,000 دقيقة/شهر ضمن الخطة المجانية [موثق سابقًا]) — يُقبل به لأن التنفيذ يكون قد اكتمل؛ وأي عمل لاحق عالي الحوسمة يفتح بقرار مالك جديد.

## الخيارات التي فُحصت

- **البقاء عامًا نهائيًا:** مرفوض — التوجيه الصريح.
- **التحويل الآن:** مرفوض — المراجعة مستمرة والبناء يحتاج الحوسبة المجانية العامة.
- **مستودعان (خاص داخلي + عام صورة):** مرفوض الآن — تعقيد مزامنة بلا حاجة مثبتة؛ يعاد فحصه عند T1 إن دعت الحاجة.
