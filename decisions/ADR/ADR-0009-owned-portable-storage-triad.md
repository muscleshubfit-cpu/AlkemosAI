# ADR-0009 — التخزين المملوك القابل للنقل: ثلاثية النسخ + عقد إعادة البناء

> الحالة: مقبول (ضمن حزمة الخطة v2.0 — اعتمدت بقرار المالك D-11 الصادر 2026-11-21 UTC) · التاريخ: 2026-11-21 · صاحب القرار: وكيل الدفعة 3 (تصميم) — الاعتماد النهائي للمالك

## السياق

توجيه المالك: «الاحتفاظ بجميع البيانات والأوزان والذاكرة وسجلات التعلم في ملفات وأصول مملوكة وقابلة للنقل بين الاستضافات» + «لا اعتماد على موارد مجانية مؤقتة باعتبارها بنية دائمة». الواقع المقيس: GitHub يرفض ملفات >100MB (والأوزان أكبر)، وHugging Face يقدم 100GB تخزين خاصًا مجانًا «بأفضل جهد» (ليس ضمانًا)، وGitHub Releases يقبل حتى 2GB للملف.

## القرار

1. **ثلاثية النسخ لكل أصل أوزان:** (1) HF Hub مستودع خاص — التخزين الأول؛ (2) GitHub Releases بوسم `model-vX.Y` — مرآة مستقلة عن HF؛ (3) نسخة محلية عند التحمين. **لا أصل أوزان في موقع واحد أبدًا.**
2. **المستودع يحمل كل ما عدا الأوزان:** الكود، البيانات، الذاكرة، سجل التعلم، وبيانات `registry/` الوصفية (روابط + SHA256).
3. **عقد إعادة البناء:** إعادة إنتاج النظام كاملًا على أي استضافة = استنساخ المستودع + تنزيل الأوزان من أي نسخة متاحة + تنزيل الأساس العام (Apache-2.0) + تشغيل البطارية للتحقق من مطابقة النتائج المسجلة.
4. **قوانين النقل (موروثة من ZERO_COST_PLAN §8 ومحدّثة):** مُخرَج واحد يعمل في أي مكان؛ لا ميزة موقع-خاصة في المسار الحرج؛ الذاكرة قابلة لإعادة الفهرسة دائمًا (النص الأصلي مخزن)؛ لكل مورد مجاني بديل ذاتي معلن؛ لا اعتماد تشغيلي على مورد يتطلب بطاقة.

## الخيارات التي فُحصت

- Git LFS داخل المستودع: مرفوض — 1GB تخزين و1GB نطاق شهري مجانًا فقط (يخنق الأوزان ويحوّل المستودع لمخزن ثقيل).
- S3/R2 أو أي تخزين سحابي: مرفوض — يتطلب بطاقة/دفعًا (تحقق 2026-11-21: R2 يطلب بطاقة حتى للتянجر المجاني).
- HF وحده: مرفوض كنسخة وحيدة — «أفضل جهد» بلا ضمان؛ المرآة على Releases تجعل الاستقلال عن أي مزود تخزين حقيقيًا.

## النتائج

- فقدان أي موقع تخزين (تغير شروط HF مثلًا) = تنزيل من المرآة، لا فقدان أصول — R-26 في سجل المخاطر.
- قابلية النقل تُثبت عمليًا بتمرين إعادة بناء دوري (ضمن بروتوكول المراجعة الشهرية).
- التكلفة: صفر (كل المواقع ضمن الخطط المجانية الموثقة).
