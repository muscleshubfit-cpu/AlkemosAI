# ADR-0012 — المستودع الأساسي alkemos-aws مصدرًا أساسيًا للمعرفة + آلية الاكتشاف التلقائي

> الحالة: مقبول (ضمن حزمة الخطة v2.1 — اعتمدت بقرار المالك D-11 الصادر 2026-11-21 UTC؛ C1 نشطة منذ دفعة 6) · التاريخ: 2026-11-21 (UTC) · صاحب القرار: وكيل الدفعة 4 (تصميم) بتوجيه مالك مباشر — الاعتماد النهائي للمالك

## السياق

1. توجيه المالك (دفعة 4): «اعتبار مستودع Alkemos الرئيسي المصدر الأساسي للمعرفة والبيانات والأنظمة، مع آلية تلقائية لاكتشاف كل إضافة أو تعديل مستقبلي وإدخاله في دورة المراجعة والتعلم».
2. الوقائع [مُقيس 2026-11-21 عبر GitHub API]: مستودع `muscleshubfit-cpu/alkemos-aws` هو مستودع الإنتاج النشط (آخر دفع `ed57082` بطابع `2026-11-21T15:18:10Z`)، عام بقرار تشغيلي مقصود موروث (DECISIONS §2 بند 3)، شجرته 8,362 مدخلًا منها 7,070 ملفًا. المستودع الخاص الأقدم `alkemos` سلف غير نشط (آخر دفع 2026-10-10). مستودع `musclehubeg-backups` يحمل لقطات يومية JSON لقاعدة Supabase ويشمل جداول مستخدمين — لذا يُقيد بقائمة بيضاء للجداول المعرفية فقط.
3. الخطة v2.0 عالجت أصول Alkemos كجردٍّ لمرة واحدة (لقطة 2026-11-21) بلا آلية اكتشاف للتغييرات اللاحقة.

## القرار

1. **alkemos-aws هو المصدر الأساسي الأول** للمعرفة والبيانات والأنظمة في AlkemosAI — كل جرد أو استشهاد داخلي يحيل إليه بالالتزام (SHA) وتاريخ الاطلاع (UTC).
2. **آلية الاكتشاف التلقائي (المراقب):** سير عمل مجدول على GitHub Actions (قراءة-فقط، بلا أسرار في تعريفه) يستطلع GitHub API العام على إيقاع معلن (تقدير البدء: كل 6 ساعات UTC) يقارن HEAD بآخر SHA مُشاهد (`research/source-watch/state.json` بطوابع UTC)، وعند كل دفعة commit جديدة يولّد «ملخص تغيير» (digest) في `research/source-watch/` يسجل: SHA، الطابع الزمني (UTC)، الملفات المتغيرة، وسوم الفرز (معرفي/غير معرفي)، وروابط الملفات المعرفية المتأثرة.
3. **الفرز والتحويل إلى دورة المراجعة:** المسارات المعرفية فقط تدخل `memory/inbox/` للمراجعة والتعلم: ملفات `src/lib/` المعرفية (بيانات/برومبتات/قوانين)، `docs/*.md` (منهجيات وتقارير)، `supabase/migrations/` (بنية البيانات). المسارات غير المعرفية (صور `public/`، ملفات القفل، مخارج البناء) تُستبعد آليًا.
4. **لقطات المحتوى اليومية:** من مستودع musclehubeg-backups تُقرأ **جداول المحتوى فقط** وفق قائمة بيضاء (blog_posts، nutrient_reference، recipes*، evo_nutrition_patterns — نفس سياسة القراءة الموروثة «بلا أي PII» في sources-log §6) — ويؤكّد المالك القائمة بقرار D-15. جداول المستخدمين وأي PII محظورة مطلقًا (SECURITY §3/§8).
5. **قراءة فقط دائمًا:** لا يكتب المراقب شيئًا إلى أي مستودع أو نظام تابع لـAlkemos ولا يلمس الإنتاج أو مزوديه — مخرجاته ملفات داخل هذا المستودع فقط.

## الخيارات التي فُحصت

- **Webhooks (دفع فوري):** يتطلب مستقبلًا مستضافًا (بنية دائمة/تكلفة) — مرفوض ضمن قاعدة صفر التزام.
- **إعادة جرد دوري يدوي بلا آلية:** مرفوض — يخالف «آلية تلقائية» ويهمل الإضافات بين الجردات.
- **مراقبة الموقع HTML بدل المستودع:** أضعف دلالة وأقل استقرارًا — المستودع مصدر الحقيقة الموثق للمعرفة والبيانات والأنظمة.

## النتائج

- المرحلة C1 في خارطة الطريق تنفذ المراقب بعد D-11 (نشطة منذ دفعة 6 — وقانون عدم الفقد في المعالجة موثق بدفعة 7)؛ معيار نجاحها (G-C1): تشغيل مستقر أسبوعين متتاليين مع digest لكل دفعة commits بلا انقطاع غير مكتشف.
- المخاطر R-27 (تغير المصدر) وR-28 (دخول PII) وR-35 (سير عمل عام) تُسجل في السجل.
- الأدلة الموثقة في `references/sources-log.md` §7.
