# ADR-0015 — نظام اكتساب المهارات: طبقة رابعة تتراكم بلا إعادة بناء

> الحالة: مقبول (ضمن حزمة v2.1 — التنفيذ ضمن C3 بعد اعتماد D-11) · التاريخ: 2026-11-22 (UTC) · صاحب القرار: وكيل الدفعة 4 (تصميم) بتوجيه مالك — الاعتماد النهائي للمالك

## السياق

1. توجيه المالك (دفعة 4): «تصميم نظام يسمح بإضافة مهارات وقدرات جديدة مستقبلًا بصورة تدريجية ومنظمة، بحيث يمكنه تعلم مجالات وأدوات وأساليب عمل جديدة دون إعادة بناء المشروع من الصفر، مع توثيق المهارات وتقييم جودتها».
2. النمط الموثق المتاح: بطاقات `SKILL.md` وفق مواصفة Agent Skills — يقرأها الوكيل فعليًا (الاسم/الوصف عند البدء، الملف كاملًا عند التطابق)؛ والمالك يملك أصلًا جاهزًا: مستودع `seo-skills` العام (30 مهارة SEO، ترخيص MIT، مواصفة Agent Skills) [مُقيس 2026-11-22].
3. الخطة v2.0 بلا طبقة مهارات: القدرة تفترض ضمن الكود/الذاكرة دون نظام إضافة منظم موثق.

## القرار

1. **الطبقة د — المهارات (`skills/`):** كل مهارة = مجلد يحوي `SKILL.md` (بطاقة: الاسم، الوصف، المجال، الإصدار وسجل تغييره، الحالة، أصل المهارة وترخيصه، خطوات التنفيذ، المدخلات/المخرجات، الأدوات وتراخيصها، أدلة الجودة) + `eval-cases.md` (حالات اختبار خاصة بالمهارة).
2. **بوابة اعتماد المهارة (G-S):** لا تُعتمد مهارة إلا بـ: (أ) توثيق كامل للبطاقة؛ (ب) حالات اختبار تنجح آليًا (GHA/CPU)؛ (ج) مراجعة عينة بشرية ثنائية اللغة؛ (د) أدلة مصدر وترخيص من القائمة البيضاء — النتائج تُوقَّع بتواريخها (UTC) وتُحفظ مع البطاقة.
3. **إضافة تدريجية منضبطة:** مجال/أداة/أسلوب عمل جديد = مهارة جديدة بإصدارها — بلا تعديل بنية المشروع ولا إعادة بناء. المهارة المهجورة تُشطب بسبب موثق (لا تُحذف).
4. **البذور:** مهارات `seo-skills` الثلاثون تُستورد عند C3 **كمرشحة** وتُكيَّف لسياق Alkemos ثم تُقيَّم فرديًا عبر G-S — لا اعتماد جماعي أعمى.
5. **قابلية النقل:** المهارات = ملفات Markdown صرفة قابلة للقراءة من أي وكيل/بيئة — أصل مملوك قابل للنقل كاملًا (عمود ملكية جديد في VISION §2).
6. **حدود التنفيذ:** لا مهارة تعدل إنتاج Alkemos أو مزوديه — مخرجات المهارات وثائق/توصيات/أصول داخل هذا المستودع فقط.

## الخيارات التي فُحصت

- **توسيع الذاكرة فقط** (بطاقات معرفة بلا حالات اختبار آلية): مرفوض — لا يحقق «تقييم الجودة» ولا قابلية التنفيذ المنضبط.
- **نظام مهارات خارج المستودع (أداة مستضافة):** مرفوض — يناقض الملكية وقابلية النقل.

## النتائج

- `skills/README.md` يوثق البنية والقواعد؛ C3 في خارطة الطريق؛ الخطر R-37 (تخفيف جودة المهارات) يُسجل.
- VISION تضيف العمود 11 (المهارات المكتسبة) وPLAN §4 تضيف الطبقة د.
