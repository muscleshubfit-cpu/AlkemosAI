# ADR-0004 — فحص AWS قراءةً فقط قبل أي قرار استضافة

> الحالة: مقبول · التاريخ: 2026-11-21 · صاحب القرار: المالك (بند إضافي بالمهمة) + وكيل التأسيس (تنفيذ)

## السياق
البند الإضافي للمهمة: فحص موارد AWS بالكامل واختيار أفضل استضافة «دون افتراض أن Lightsail هو الخيار الأفضل مسبقًا»، ودون إنشاء موارد مدفوعة أو تغيير البنية قبل تقديم الخطة والتكلفة والموافقة، مع حماية خدمات Alkemos القائمة.

## القرار
1. الفحص **قراءة فقط** حصريًا (describe/list/get عبر CLI) — نُفذ 2026-11-21 ووثق في `docs/03-infrastructure/aws-audit.md`.
2. لا إنشاء أي مورد مدفوع ولا تعديل أي موجود إلا بعد خطة + تكلفة + موافقة مالك موثقة.
3. مثيل الإنتاج `alkemos-test` **منطقة محرمة** لأي عمل من أعمال AlkemosAI.
4. النتيجة الحاسمة الموثقة: قيود SCP تمنع EC2/GPU داخل الحساب — رُفع القرار للمالك (D-3) ولم يُفترض أي حل مسبقًا (بما فيه Lightsail).

## الخيارات التي فُحصت
فحص جزئي عبر وحدة التحكم فقط: رُفض — لا يوثق ولا يتكرر آليًا. فحص يصل للإنفاق التجريبي (مثل استدعاء Bedrock واحد): رُفض — ينتهك شرط الموافقة المسبقة.

## النتائج
صورة موثقة قابلة لإعادة الإنتاج (الأوامر محفوظة) + اكتشافات حاسمة (SCP/$0 تكلفة/Bedrock متاح للفهرسة) + صفر أثر على الإنتاج. أثر مراقب: فحص الهوية كشف غياب MFA — رُفع كتوصية أمنية للمالك.
