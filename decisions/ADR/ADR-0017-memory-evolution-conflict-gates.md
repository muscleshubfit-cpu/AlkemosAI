# ADR-0017 — تطوير الذاكرة: كشف التعارضات، إدارة النسخ القديمة، وتعميم بوابات الاعتماد ثنائية اللغة

> الحالة: مقبول (ضمن حزمة v2.1 — يُدمج في M1 وما بعده بعد اعتماد D-11) · التاريخ: 2026-11-21 (UTC) · صاحب القرار: وكيل الدفعة 4 (تصميم) بتوجيه مالك — الاعتماد النهائي للمالك

## السياق

1. توجيه المالك (دفعة 4): «فصل قاعدة المعرفة والذاكرة والمهارات عن أوزان النموذج [قائم في ADR-0008]، وبناء آلية تراكم وتحديث واكتشاف التعارضات والنسخ القديمة، مع **تقييم ثنائي اللغة يثبت التحسن قبل اعتماد أي تعلم جديد**».
2. ADR-0008 وضع دورة دفعات ببوابة G-Q **للأوزان** حصرًا؛ إدخال المعرفة/الذاكرة في v2.0 كان بمراجعة عينة بشرية بلا بوابة مقيسة موحدة، وبلا آلية تعارضات وبلا إدارة نسخ قديمة.

## القرار

1. **بطاقة المعرفة v2:** حقول إلزامية إضافية إلى بنية v2.0: الإصدار، تاريخ آخر مراجعة (UTC)، الحالة، `superseded-by`، `contradicts`، والأصل الكامل (المصدر + الالتزام/الرابط + تاريخ الاطلاع).
2. **كشف التعارض إلزامي عند كل اعتماد:** قاعدة الكيان/الحقل — قيمة جديدة تخالف قائمة → علامة تعارض + إدخال في قائمة قرار المراجعة؛ **لا كتابة صامتة فوق معرفة قائمة**. الحسم بالموثوقية والتوثيق والأحدث؛ الخاسر يُشطب بسبب موثق ويُؤرشف (لا حذف — التاريخ محفوظ دائمًا).
3. **بوابات معممة ثنائية اللغة:** **G-K** (اعتماد معرفة/بيانات) و**G-S** (اعتماد مهارات — ADR-0015) إلى جانب **G-Q** (أوزان). كلها: لا اعتماد بلا دليل + نتائج موقعة بتواريخ UTC + فحص ثنائي اللغة (العربية والإنجليزية سليمتان معًا) + إثبات إضافة/تحسن مقيس قبل الاعتماد.
4. **إثبات التحسن قبل أي اعتماد:** للمعرفة: إضافة موثقة مقيسة (بطاقات/أزواج جديدة، تعارضات محلولة) بقياس قبل/بعد في سجل التعلم؛ للمهارات: نجاح حالات اختبارها؛ للأوزان: دلتا البطارية وقانون الانحدار (كما هو في G-Q).
5. **سجل التعلم يسجل الأنواع الثلاثة** (معرفة/مهارة/أوزان) — «ضمير التراكم» يغطي كل دخول، لا الدفعات التدريبية فقط.

## الخيارات التي فُحصت

- **إبقاء المراجعة البشرية العشوائية وحدها:** مرفوض — لا تكشف التعارضات منهجيًا ولا تثبت التحسن قبل الاعتماد.
- **إعادة بناء الذاكرة عند كل تعارض:** مرفوض — يخالف التراكم؛ الشطب الموثق + الأرشفة يحفظان التاريخ وسبب القرار.
