# skills/ — الطبقة د: المهارات المكتسبة

هذا المجلد يحمل **المهارات المملوكة القابلة للنمو التدريجي**: بطاقات `SKILL.md` موثقة مقيمة الجودة تتيح للنظام والوكلاء تعلم مجالات وأدوات وأساليب عمل جديدة **بلا إعادة بناء المشروع** (ADR-0015).

## البنية

```
skills/
  <skill-name>/
    SKILL.md        # بطاقة المهارة (متوافقة مع نمط Agent Skills: الاسم/الوصف أولًا، التفصيل عند التطابق)
    eval-cases.md   # حالات اختبار المهارة — عقد بوابة G-S
```

## حقول بطاقة SKILL.md (إلزامية)

الاسم · الوصف · المجال · الإصدار وسجل تغييره · الحالة (مسودة/مرشحة/معتمدة/مهجورة) · أصل المهارة وترخيصه (قائمة بيضاء: ملك Alkemos · MIT · Apache-2.0 · ملك عام) · خطوات التنفيذ · المدخلات/المخرجات · الأدوات وتراخيصها · أدلة الجودة (نتائج G-S بتواريخها UTC).

## القواعد (من ADR-0015)

1. **بوابة G-S قبل أي اعتماد:** توثيق كامل + حالات اختبار تنجح آليًا (GHA/CPU) + مراجعة عينة بشرية ثنائية اللغة + أدلة مصدر/ترخيص — النتائج موقعة بتواريخ UTC.
2. **إضافة تدريجية منضبطة:** مجال/أداة/أسلوب جديد = مهارة جديدة بإصدارها — لا تعديل بنية المشروع. المهارة المهجورة تُشطب بسبب موثق (لا تُحذف).
3. **البذور مرشحة لا معتمدة:** مهارات `seo-skills` الثلاثون (MIT) تُستورد عند C3 كمرشحة وتُكيَّف لسياق Alkemos ثم تُقيَّم فرديًا عبر G-S — لا اعتماد جماعي أعمى.
4. **قابلية النقل:** ملفات Markdown صرفة تقرؤها أي بيئة/وكيل — أصل مملوك قابل للنقل كاملًا (عمود الملكية 11).
5. **حدود التنفيذ:** لا مهارة تعدل إنتاج Alkemos أو مزوديه — مخرجاتها وثائق/توصيات/أصول داخل هذا المستودع فقط (R-36).

## الحالة الآن

المجلد فارغ عمدًا — أول المهارات تُنشأ في **C3 بعد اعتماد D-11** (بذور: مهارات SEO من مستودع المالك `seo-skills`).
